How to download:

Go to https://transparency.entsoe.eu/
Make free account
Click countries
Click NL on map
Click Generation: Actual Generation per Production Type
Click Table (default is Graph)
Select Date (Max 7 days, but only the year is important)
Click 3 dot menu: Export -> Export to CSV (year)

Structure
Actual Generation per Production Type
MTU (CET/CEST),"Area","Production Type","Generation (MW)"
Timestamp every 15 min (CET 01/01/2014 00:00:00 - 01/01/2014 01:00:00), MW, MW


Installed Capacity per Production Unit
Time Interval,"Area","Production type","Code","Name","Installed Capacity at the beginning of the year (MW)","Current Installed Capacity (MW)","Location","Voltage Connection (kV)","Commissioning Date","Decommissioning Date"

Installed Capacity per Production Type
Time Interval,"Year","Area","Production Type","Installed Capacity (MW)","Total Grand Capacity (MW)"
